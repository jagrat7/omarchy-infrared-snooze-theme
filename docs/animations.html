Closing a window: windowsOut + fadeOut

The window shrinks/slides with windowsOut while fadeOut fades it at the same time, and the neighbour grows into the gap with windowsMove. If you slow windowsOut, slow fadeOut too, or the window is already invisible before the motion finishes. Click a screen to get its config line.







  
Switching workspaces: workspaces

  
The percentage is how far the workspace travels, as a share of the screen. Your scratchpad (specialWorkspace) takes the same styles and uses slidefadevert 20%. Omarchy's own default turns this animation off, so switching is instant.
